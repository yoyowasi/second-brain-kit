무인 실행 루틴이다. 사용자는 자리에 없으니 질문하지 않는다. 먼저 볼트의 `AGENTS.md`를 읽고, 그 규칙대로 끝까지 처리한 뒤 결과를 짧게 출력한다.

1. 오늘 날짜(사용자 로컬 시간)의 `10_Daily/YYYY-MM-DD.md`가 없으면 `99_System/Templates/Daily.md` 구조로 만든다. 템플릿의 Templater 구문(퍼센트 기호와 꺾쇠 괄호로 감싼 부분)은 실제 값으로 바꿔 쓴다. second-brain 스킬의 보조 도구를 쓸 수 있으면 `sb.py new daily`로 만든다. 이미 있으면 지우거나 덮어쓰지 않는다. 다른 폴더에 같은 이름 파일이 있어 만들 수 없으면, 그 파일을 옮기거나 고치지 말고 경로를 출력한 뒤 끝낸다.
2. `10_Daily/`의 지난 일일 노트(`Weekly/` 제외)에서 작성일이 2일 넘게 지난 미완료 `- [ ]` 항목을 찾는다(`sb.py tasks --older 2`). 복사하지 않는다.
3. 찾은 항목이 있으면 오늘 노트 `## 할 일` 아래에 다음 형식으로 한 번만 적는다. 같은 블록이 이미 있으면 그 블록만 갱신한다.
   `> 🤖 2일 넘은 미완료: [[YYYY-MM-DD]] 항목 요약, ... — 프로젝트로 옮길지 정해 주세요.`
4. `20_Projects/`의 `status: active` 프로젝트 이름을 오늘 노트 `## 오늘 집중할 것` 아래에 주석 한 줄로 알린다. 이미 있으면 갱신한다.
   `<!-- 진행 중: [[프로젝트1]], [[프로젝트2]] -->`
5. 오늘 노트 외의 파일은 수정하지 않는다.
