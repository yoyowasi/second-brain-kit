무인 실행 루틴이다. 사용자는 자리에 없으니 질문하지 않는다. 먼저 볼트의 `AGENTS.md`를 읽고, 그 규칙대로 끝까지 처리한 뒤 결과를 짧게 출력한다.

1. 오늘 날짜(사용자 로컬 시간)의 `10_Daily/YYYY-MM-DD.md`를 읽는다. 없으면 아무것도 만들거나 바꾸지 말고 "오늘 노트 없음"만 출력하고 끝낸다.
2. `## 기록`에 오늘 끝낸 할 일(`- [x]`)과 메모를 바탕으로 3~6줄 요약을 쓴다. 요약 첫 줄은 `- 🤖 요약:`으로 시작한다. 이미 그 요약이 있으면 새로 덧붙이지 말고 그 요약만 최신 내용으로 바꾼다. 사용자가 직접 쓴 다른 줄은 그대로 둔다.
3. 다시 겪을 만한 문제 해결 사례(현상·원인·해결이 보이는 것)가 있으면, 해결 기록 노트를 만들지 말고 `## 메모 · 떠오른 생각`에 `- 🤖 해결 기록 후보: 증상 한 줄`로만 적는다. 같은 후보가 이미 있으면 추가하지 않는다.
4. 영구 노트로 정제할 만한 생각이 있으면 같은 곳에 `- 🤖 노트 정제 후보: 한 줄 주장`으로 최대 2개까지 적는다.
5. 미완료 할 일은 옮기거나 복사하지 않는다. 남은 개수만 출력한다.
6. 오늘 노트에 없는 내용을 지어내지 않는다. 오늘 노트 외의 파일은 수정하지 않는다.
