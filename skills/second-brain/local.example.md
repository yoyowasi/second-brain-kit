# local.md — 내 볼트 전용 설정 (예시)

이 파일을 `~/.second-brain/local.md`로 복사해 고친다(Claude Code·Codex 설치가 함께 쓴다). 스킬은 시작할 때 `sb where`가 알려 주는 이 파일을 읽는다.
`local.md`는 개인 설정이라 공개 저장소에 올리지 않는다. 볼트 규칙 자체는 볼트의 `AGENTS.md`에 두고, 여기에는 **다른 프로젝트 세션에서 볼트를 쓸 때 필요한 것**만 적는다.

## 볼트
- 위치: `~/Documents/SecondBrain` (실제 경로는 `sb setup`이 `~/.second-brain/config.json`에 저장한다)
- Obsidian 볼트 루트가 이 폴더보다 위라면 적는다: 예) 볼트 루트는 상위 `Notes/`, 링크는 `[[Notes 기준 경로]]`
- 동기화: 예) Obsidian Git이 주기적으로 private 저장소에 자동 push → 에이전트는 commit·push 하지 않는다

## 더 읽어도 되는 곳 (사용자가 지정할 때만)
- 예) `../업무 일지/` — 날짜별 업무 원본(`YYYY-MM-DD.md`)

## 열지 않는 곳
- 예) `../회사자료/`, 이름에 토큰·비번이 든 파일

## 태그 어휘
대시보드(영역 노트의 Dataview)가 이 목록으로 묶는다. 목록 밖 태그는 만들기 전에 묻는다.
- 주제: 예) `frontend`, `backend`, `db`, `dev-env`
- 도메인: 예) `결제`, `회원`
- 상태: `미결`

## 기록 정책
- 예) 작업 중 다시 쓸 원인·환경 특성·규칙을 확인하면 묻지 않고 해결 기록·참고 자료로 남기고 보고에 밝힌다.
- 예) 또는: 작업 끝에 "해결 기록으로 남길까요?"라고 제안만 한다.

## 프로젝트 연결 (저장소·작업 → 볼트 노트)
| 작업 위치 | 기록할 프로젝트 노트 |
|---|---|
| 예) `~/code/shop-web` | `[[쇼핑몰 리뉴얼]]` |
| 맞는 프로젝트가 없음 | 일일 노트에만 쓰고, 프로젝트를 만들지 묻는다 |

## 저장소 노트 (`/init-project`, Claude Code)
- 회사 프로젝트 폴더: 예) `~/work` — 그 아래 저장소 노트는 `area: "[[업무]]"`, 그 밖(개인 저장소)은 `area: "[[학습]]"`

## Claude Code hook (설치했을 때)
- 세션 일지·dream에서 뺄 작업 폴더는 `config.json`의 `journal_exclude`에 경로 조각으로 적는다. 예) 개인 문서 폴더
- 세션 일지·dream 제안도 볼트 노트라 볼트 백업(git 등)에 함께 올라간다. 올리고 싶지 않은 폴더의 세션은 위 목록에 넣는다.

## 검증 범위 라벨
- 예) `코드(정적: type-check)`, `API`, `DB(dev|운영)`, `브라우저(dev, 날짜)`, `운영`

## 자동 루틴
- 예) 평일 09:00 아침 오늘 노트, 금 16:00 주간 리뷰 (`99_System/Routines/`). 루틴이 쓰는 블록은 수동 작업에서 중복으로 만들지 않는다.
