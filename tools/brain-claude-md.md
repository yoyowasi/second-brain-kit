# Second Brain
- 세컨드 브레인은 Obsidian 볼트다. 위치는 second-brain 스킬의 `sb.py where`가 알려 준다. 읽거나 쓰기 전에 볼트 `AGENTS.md`(볼트 규칙)를 먼저 읽고, 다루는 방법은 `second-brain` 스킬을 따른다.
- "기억해", "브레인에 넣어", "메모해 둬", "인박스 정리", "오늘 기록"은 어느 프로젝트에 있든 이 볼트에 한다(볼트 파일은 절대 경로로). 단 "기억해"가 Claude 작업 방식에 대한 교정·규칙이면 볼트가 아니라 해당 프로젝트 메모리에 쓴다(모든 프로젝트 공통이면 전역에 둘지 묻는다). 지식·사실·결정은 볼트에.
- 질문이 내 프로젝트·과거 결정·전에 정리한 지식·전에 해결한 문제에 관한 것이면 답하기 전에 볼트를 찾는다: `99_System/색인.md`에서 노트를 골라 열고, 없거나 날짜·세부가 필요하면 볼트 안에서 `rg -il <키워드>`.
- 답이 다시 쓸 만한 종합·비교·분석이나 웹 조사 결과면 답 끝에 "브레인에 남길까요?"를 한 줄로 묻는다. 단순 사실 확인, 코드 작업 보고, 이미 볼트에 있는 내용이면 묻지 않는다. 해결 기록은 `~/.second-brain/local.md` 기록 정책을 따른다.
- 세션이 끝나면 hook이 `10_Daily/Journal/`에 한 줄 일지를, 하루 한 번 dream이 `00_Inbox/`에 규칙 제안을 남긴다. 규칙은 `/inbox`에서 내가 승인한 것만 아래에 들어간다. 세션 맥락의 `[brain] ...` 줄은 첫 답 끝 한 줄 제안으로만 쓴다.
- 볼트 git 커밋·push는 내가 요청할 때만 한다(Obsidian Git 같은 백업 도구를 쓰면 그 도구 몫).
